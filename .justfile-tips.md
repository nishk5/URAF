# just Tips & Tricks

## Why just over Make?

1. **Better Syntax**
   - No tab vs space issues
   - Clear, readable recipes
   - Better error messages

2. **Cross-Platform**
   - Works identically on Windows, macOS, Linux
   - No need for GNU Make on Windows

3. **Modern Features**
   - Command parameters: `just test-file mytest.py`
   - String interpolation: `{{variable}}`
   - Conditional execution
   - Better command listing

## Quick Examples

```bash
# List all available commands
just --list

# Run with parameters
just test-file tests/test_prm.py
just test-match "test_tool"

# Chain commands
just fix lint test

# Dry run (show what would be executed)
just --dry-run test

# Choose a recipe interactively
just --choose
```

```bash
# Homebrew (macOS/Linux)

# Pacman (Arch Linux)
pacman -S just

# Chocolatey (Windows)
choco install just

```

## justfile vs Makefile

| Feature | Makefile | justfile |
|---------|----------|----------|
| **Whitespace** | Tabs required | Spaces work |
| **Parameters** | Complex `$1` | Simple `{{arg}}` |
| **Listing** | Custom recipe | Built-in `--list` |
| **Defaults** | `.DEFAULT_GOAL` | First recipe |
| **Cross-platform** | Requires GNU Make | Built-in |
| **Error messages** | Cryptic | Clear & helpful |

## Pro Tips

1. **Set a default recipe**
   ```just
   # First recipe runs by default
   default:
       @just --list
   ```

2. **Use @ to suppress echo**
   ```just
   clean:
       @echo "Cleaning..."  # @ = don't echo command
       rm -rf dist
   ```

3. **Conditional recipes**
   ```just
   test:
       @if [ -d .venv ]; then \
           uv run pytest; \
       else \
           echo "Run 'just dev' first!"; \
       fi
   ```

4. **Recipe dependencies**
   ```just
   # Run lint before test
   test: lint
       uv run pytest
   ```

5. **Private recipes (start with _)**
   ```just
   _private:
       echo "Won't show in --list"
   ```

## IDE Integration

### VS Code
Install extension: **skellock.just** (syntax highlighting)

### Vim/Neovim
```vim
" Add to .vimrc
autocmd BufNewFile,BufRead justfile set filetype=just
```

```elisp
;; Add to .emacs or init.el
(require 'just-mode)
```
